1. این بررسی، crawl زنده همه URLها از Netlify، تست موبایل واقعی، Lighthouse/Core Web Vitals، یا بررسی Search Console نیست.
2. معتبر بودن ادعاهای تجاری و کیفیت هتل‌ها به‌طور مستقل تضمین نشده؛ برای دو مورد از صفحات رزرو ثالث استفاده شده و مشخص شده که اطلاعات از همان منابع آمده است.

5. این تغییرات روی GitHub ثبت شده‌اند، اما سایت مستقر یا منتشر نشده است.
